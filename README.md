# Méthodes d'apprentissage en machine learning: apprentissage Supervisé/Non-supervisé
Objectif: Analyse et segmentation d'un portefeuille d'assurés afin d'optimiser la modélisation du risque de sinistralité

Ce projet a pour objectif d’explorer en profondeur l’ensemble des méthodes d'apprentissage en machine learning appliquées une base de données d’assurance automobile. Après une phase rigoureuse
de nettoyage, d’analyse exploratoire et de préparation des variables, deux grandes
familles de modèles ont été mises en uvre : les modèles supervisés et les modèles non supervisés.
